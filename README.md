# PL
## O projekcie
Jest to prosta strona do szukania najnowszych wersji instrukcji kolejowych.
Denerwowało mnie, że w internetowych wyszukiwarkach wskazywane pliki do pobrania były zazwyczaj nieaktualne.
Dlatego zrobiłem swoją wyszukiwarkę pozwalającą szybko znaleźć instrukcję, która jest najnowsza i obowiązująca.

## Funkcje
- [x] Wyszukiwanie według:
  - [x] numeru instrukcji
  - [x] słowa kluczowego (w nazwie instrukcji)
- [x] Informacja od i do kiedy instrukcja obowiązuje
- [x] Informacja czy wersja instrukcji jest oznaczona jako WCAG
- [ ] Możliwość zobaczenia starych wersji instrukcji
- [ ] Lista ostatnio zmienionych instrukcji (na stronie głównej)

## INFORMACJA !!!
Autor **nie jest** powiązany z PKP PLK, projekt ma na celu jedynie udostępnienie danych dostępnych już w internecie w bardziej przystępnej formie.

# EN
## About the project
This is a simple website for searching up-to-date Polish railway rulebooks.
It used to annoy me that the downloadable files listed by online search engines were usually out of date.
That’s why I created my own search engine, which allows you to quickly find the most recent and current version of a rulebook.

## Features
- [x] Search by:
    - [x] rulebook number
    - [x] keyword (in the rulebook title)
- [x] Information about when the rulebook comes into and out of force
- [x] Information on whether the rulebook version is marked as WCAG-compliant
- [ ] Option to view previous versions of the rulebooks
- [ ] List of recently updated rulebooks (on the homepage)

## IMPORTANT INFORMATION!!!
The author **is not** affiliated with PKP PLK; the aim of this project is solely to make data already available online accessible in a more user-friendly format.
